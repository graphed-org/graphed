PyTorch input layout
~~~~~~~~~~~~~~~~~~~~

The PyTorch plugin takes ``params={"order": "F"}`` to feed the model a column-major input matrix,
the strides a pandas-fed ``torch.FloatTensor(df.to_numpy())`` has. torch keeps numpy's strides and
its matrix multiply rounds by layout, so this reproduces such an evaluation bit for bit. The order
is a recorded param, so the two layouts are two nodes; the row-major default (no ``order``) is
unchanged.
